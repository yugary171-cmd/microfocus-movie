# 管理端界面规范

本规范约束 PC 管理后台（`apps/admin`）的通用视觉与布局。实现以 `apps/admin/src/styles/tokens.css` 和 `apps/admin/src/styles/global.css` 为准；页面不得再复制一套颜色、气泡或操作列定位。

## 气泡 / Tooltip

截断文本需要展示完整内容时，使用全局 `.tooltip`，不要用浏览器原生 `title`，也不要临时写深色浮层。

- 容器加 `.has-tooltip`；气泡加 `.tooltip`，向上弹出再加 `.tooltip--above`。
- 外观：白底（`--color-surface`）、灰色描边（`--color-border`）、正文色文字、轻阴影。宽度按内容撑开，上限 `min(90vw, 420px)`，单行不换行。
- 只展示被截断的那条信息（例如完整邮箱），不要把旁边已经可见的角色、状态再塞进气泡。
- 悬停与键盘聚焦（`:focus-visible`）都应显示。

## 表格操作列

横向滚动的数据表，最后一列若是「操作」，必须使用 `.table-wrap--sticky-actions`。

- 操作列贴在表格可视区域右侧，小屏横向滑动时不被其他列挡住。
- 列宽保持稳定（最小约 88px），表头与单元格共用同一套白底/表头底，避免透出后面的单元格。
- 行悬停时，粘滞单元格背景与普通行悬停一致。
- 操作菜单本身用浮层（`position: fixed`）挂到按钮附近，不得撑开表格行高；同一时间只开一个菜单，点击外部关闭。

## 密码输入框

密码、确认密码一律使用 `.password-field`（`PasswordField` 组件）：右侧眼睛按钮切换明文/掩码，默认掩码。登录页与开通页共用，不要再各写一套。
