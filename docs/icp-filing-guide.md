# 微信小程序备案操作手册（甲方自办）

> 适用场景：小程序尚未开发完成，由主体方（甲方）全程自行完成 ICP 备案。
> 本手册以**企业主体**为主线编写，个人主体的差异见「个人主体与企业主体的差异」一节。
> 整理日期：2026-08-16。依据微信官方《小程序备案操作指引》《备案材料示例》《备案常见问答》整理，官方文档链接见文末。

**结论先行**：备案不要求小程序开发完成或已上线，审核的是主体信息与小程序信息（名称、服务内容等），反而小程序必须**先完成备案才能发布上架**。全流程顺利约 1–3 周，建议与开发并行尽早办理。

---

## 〇、开始前确认（约半天）

### 账号前提

- 备案在小程序管理后台发起，需持有该小程序的**管理员账号**（AppID 归属甲方主体）。
- 小程序尚未注册的：到 [mp.weixin.qq.com](https://mp.weixin.qq.com) 用一个未绑定过公众平台的邮箱注册，主体选企业，按提示完成工商信息登记与验证（营业执照、对公打款或法人验证）。
- 账号目前由开发方持有的：请开发方在后台「成员管理 → 管理员」将管理员更换为甲方人员。
- 确保小程序已完成**注册认证**（企业主体的微信认证/法人验证）；备案入口不显示通常是账号未完成认证。
- 确保小程序**基本信息已填好**：名称、头像、简介、服务类目。备案信息须与这些保持一致。

### 材料清单（企业主体）

| 材料 | 要求 |
| --- | --- |
| 营业执照 | 原件拍照或彩色扫描（不接受复印件、黑白件、翻拍、电子证照），边框完整清晰，JPG/JPEG/PNG，约 100K–200K，分辨率 ≥1500×1100，距到期 >3 个月（宁夏 >6 个月） |
| 法定代表人身份证 | 原件拍照/彩色扫描，四周圆角及边缘清晰，分辨率 ≥720×1280 |
| 小程序负责人身份证（如与法人不同） | 同上 |
| 负责人本人手机号 | 一人一号，不得与他人共用，全程保持畅通 |
| 《主体负责人授权书》（仅负责人非法人时） | 加盖**单位公章**（不接受合同章、项目章），法定代表人**手写正楷签名**（不接受连笔），签署日期与提交备案同日或 1 个月内 |
| 负责人本人微信 | 用于人脸核验，须为**中国大陆实名微信号**（港澳台微信号不支持） |

### 个人主体与企业主体的差异

两类主体的**操作流程完全一致**（发起备案 → 填写主体信息 → 填写小程序信息 → 人脸核验 → 平台初审 → 短信核验 → 管局审核），差异集中在材料、负责人规则和服务内容选择：

| 事项 | 企业主体 | 个人主体 |
| --- | --- | --- |
| 主要材料 | 营业执照 + 法定代表人/负责人身份证 | 仅负责人身份证（跨省备案需加居住证/暂住证） |
| 主体负责人 | 通常为法定代表人，部分省份可授权高管担任（需授权书） | 必须为本人，不适用授权书 |
| 承诺书 | 法定代表人正楷签名 + 单位公章 | 负责人签名 + 手写身份证号 + 日期 |
| 服务内容 | 按实际经营范围勾选 | 不得勾选经营性/企业性内容 |
| 备案数量上限 | 50 个 | 5 个 |
| 人脸核验 | 小程序负责人（管理员）本人 | 主体负责人即小程序负责人，均为本人 |

个体工商户按单位类主体流程操作，另注意：

- 无公章的，承诺书须负责人手写签名 + 日期 + 手印 + 身份证号，并在备注注明「个体工商户无公章」（上海、江苏、宁夏、福建要求必须刻章）。
- 福建个体户负责人必须为法定代表人。

**主体类型尽早确定**：影视/视频类服务类目个人主体基本无法申请（微信对个人开放的类目非常有限），视频类小程序实际上只能走企业主体；小程序注册后更换主体等于注销重做，备案也需重新办理。

### 提前自查两项

1. 负责人身份证地址与备案省份不一致的（涉及吉林、上海、江苏、浙江、安徽、山东、湖北、广东、四川、贵州、云南），需额外准备居住证/暂住证。
2. 通讯地址须为实际可联系地址，**精确到门牌号**（北京地址不能含 `#` 等特殊符号）。

## 一、发起备案

1. 电脑登录 [mp.weixin.qq.com](https://mp.weixin.qq.com)，管理员微信扫码。
2. 未上架小程序：首页点击【去备案】；也可在 **设置 → 小程序备案** 点击【去备案】。
3. 备案类型选择**新增备案**（首次）。
4. 选择主体所在省市区：按营业执照登记地址选择；自贸区按实际行政区选择（如天津自贸区选「滨海新区」）；**浙江、广西不要选「市辖区」**。
5. 注意：工商数据有 5–15 个工作日同步延迟，新注册公司可能比对不上，可等几天再提交。

## 二、填写主体信息

- 对照营业执照如实填写主办单位名称、统一社会信用代码等；大小写、全半角须与工商数据完全一致，否则驳回。
- 按上表标准上传营业执照照片。
- **主体负责人**：个人主体必须是本人；企业主体通常由**法定代表人**担任。部分省份（如天津、上海、浙江）不允许授权他人；北京、海南等地可由高管担任（部分地区需上传授权书）。不确定时填写法定代表人本人最稳妥。
- 手机号填写负责人本人常用号码——初审和管局阶段都可能**电话回访（0755 开头）**，不接听会被驳回。

## 三、填写小程序信息

- **服务内容**：按小程序实际运营内容勾选。个人主体不得勾选经营性/企业性内容；非政府机关、事业单位不得选「政务民生」。
- **不涉及前置审批时，务必勾选「以上都不涉及」**。前置审批类别包括：出版、网络视听、药品医疗器械、文化、新闻、网约车、校外培训、宗教、互联网金融——勾选了就必须上传对应许可证。
- **小程序名称**不能含前置审批关键词（金融、医药、新闻、教育、出版、网约车等），含了会被驳回，需先改名。
- ⚠️ **视频类小程序特别提醒**：涉及影视/视频播放的小程序，在微信侧申请「影视/视频」服务类目时，微信会单独要求类目资质（如营业执照含相关经营范围、《广播电视节目制作经营许可证》等）——这是**微信服务类目审核**，与 ICP 备案是两件事。ICP 备案里的「服务内容」须与实际功能相符，但只有真正从事网络视听节目服务才需要《信息网络传播视听节目许可证》；普通影视资讯/剪辑类小程序通常不勾前置审批。拿不准时在勾选前咨询微信客服或属地管局确认。

## 四、上传附件与承诺书

- 按页面提示上传证件照片，逐项对照材料清单的质量标准。
- **承诺书**：多数省份由平台自动生成，线上确认即可；**广东、新疆**需下载对应版本签字盖章后上传；北京（名称含「教育/培训」「金融/理财」等关键词）、湖北、浙江、江苏、重庆等有各自的补充承诺书要求，页面会自动提示。
- 授权书/承诺书的日期统一写**提交备案当天**（或 1 个月内），避免因日期过期被驳回。

## 五、人脸核验（小程序负责人本人）

- 小程序负责人即小程序**管理员**，填写的身份信息必须与管理员微信实名信息一致，否则核验直接失败。
- 用负责人本人的中国大陆微信号扫码核验，要求：
  - 白色或浅色干净背景，无杂物、无他人入镜；
  - 不戴帽子、耳机、口罩，不裸露上半身，表情自然、不闭眼；
  - 失败可换网络、更新微信版本、换浏览器后重试。

## 六、提交平台初审

- 提交后 **1–2 个工作日**内出结果，通过站内信和模板消息通知；被驳回按意见修改重提（重提审核时效 7 个工作日）。
- 初审期间保持电话畅通。
- 存量小程序每日提交有动态配额，用完次日早 10 点刷新。
- 备案数量上限：企业 50 个，个人/个体工商户 5 个。

## 七、工信部短信核验（24 小时内，最容易出错的一步）

- 初审通过、提交管局后，工信部（**12381**）会向**主体负责人和小程序负责人**手机发送核验短信——两部手机都要有人盯。
- 收到后 **24 小时内**登录 [beian.miit.gov.cn](https://beian.miit.gov.cn)（手机或电脑均可）完成核验。超时未核验，备案自动退回，流程作废重走。
- 验证码填错可触发一次重发。

## 八、通管局审核

- 各省通信管理局 **1–20 个工作日**内出结果，通过站内信、模板消息、短信通知。
- 期间仍可能有管局电话回访，如实回答即可。

## 九、备案成功后

- 审核通过后下发小程序备案号，之后才能**发布上架**（未备案小程序发布会报错码 86369）。
- 备案号由平台**自动展示**在小程序「更多资料页」，无需开发自行悬挂。
- 后续义务：小程序名称、服务内容、负责人、主体证件等信息变化时，须及时发起**变更备案**（统一社会信用代码变更不支持直接变更，只能注销后重新备案）；逾期不变更会被警告、封禁功能甚至强制注销备案。

## 时间线与人员安排一览

| 阶段 | 耗时 | 需要谁 |
| --- | --- | --- |
| 准备材料、拍照、刻章（如需） | 0.5–1 天 | 行政 / 法人 |
| 后台填写 + 人脸核验 + 提交 | 0.5 天 | 管理员 + 负责人本人（人脸） |
| 平台初审 | 1–2 个工作日 | 负责人保持电话畅通 |
| 短信核验 | 收到短信后 24 小时内 | 主体负责人 + 小程序负责人 |
| 管局审核 | 1–20 个工作日 | 同上，接听回访 |

必须本人到场的只有三个时刻：**人脸核验**（约 5 分钟）、**接回访电话**、**短信核验**（约 2 分钟），其余步骤均可由行政人员代为填写。

## 常见驳回原因（提前规避）

- 工商信息比对不一致（大小写、全半角、省市区选错、新公司工商数据未同步）；
- 营业执照/身份证照片为复印件、翻拍、遮挡、过期或分辨率不够；
- 负责人与法人不一致但该省不支持授权，或授权书用了合同章/连笔签名/日期超期；
- 手机号非本人使用或无法接通、回访电话漏接；
- 小程序名称含前置审批关键词；
- 服务内容勾选了前置审批类目但未上传资质；
- 与工信部已有备案信息冲突（该主体在其他平台存在未结案的备案）。
